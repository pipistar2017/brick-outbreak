# 积木 / 尸潮 — Brick Outbreak MVP 0.4.0

原生 3D 单机生存游戏。Godot 4.6.3，采用可活动关节的程序化积木武将与 3D 场景，中文界面，无需联网。


## 0.4.0：真正的积木丧尸

![五类丧尸的实际 3D 图鉴](dist/zombies.png)

| 类型 | 形象特点 |
|---|---|
| 蹒跚丧尸 | 腐化灰绿肤色、黑眼窝、缺齿垂颌、残破蓝灰衣物、露骨伤痕，双臂前伸、拖腿蹒跚 |
| 狂奔丧尸 | 瘦削身躯、低伏前倾、破损兜帽、裸露脊骨、长骨爪，不对称摆臂快速追击 |
| 重甲丧尸 | 肿大紫灰身躯、歪斜破盔、锈蚀胸甲与单侧肩甲、露出腐化面部，重拳扑击 |
| 疫毒喷吐者 | 黄绿肤色、肿胀腹部、背部毒囊、酸蚀巨口与断齿，从嘴部喷出绿色毒液 |
| 异变首领 | 巨型身躯、畸变巨臂、骨刺脊背与断齿利爪，体型仍为普通敌人的 2.5 倍 |

五类模型均接入实际刷新与战斗，保留原有血量、伤害、移动速度和攻击间隔。新增头部歪斜、垂颌、扑咬与伸爪、拖腿和不对称步态；战斗个体使用随机动作相位，避免整齐踏步。冰霜减速同步放慢步态，命中闪白与冰冻覆盖作用于完整模型。

在选人界面右上角点击 **丧尸图鉴**，可拖动五类真实模型查看侧面与背面。[查看背部毒囊与骨刺](dist/zombies-back.png)。图鉴为便于比较采用相近展示尺寸，实际战斗仍使用各类型体型倍率。

渲染时按关节与材质合并细节并缓存网格，同类个体共享几何。喷吐弹从模型嘴部发射，保留可闪避的飞行与原有伤害。仍采用原创积木玩具风格，不是写实恐怖美术。

## 0.3.0：能看清的普攻与技能

[观看 18 秒实机战斗演示](dist/combat-demo.mp4)

- **普通攻击**：青龙战将增加蓄力、身体带动挥刀与扇形刀光；游侠增加连弩后坐、枪口闪光、金色弹道；术士增加法杖抬手、冰弹飞行和冰晶命中碎片。
- **技能区分**：青龙横扫为环形旋斩，破阵突击为绿色冲锋残影；爆裂弹为橙色爆炸与冲击波，火力全开为持续环绕的强化光效；冰霜新星为冰晶扩散，极寒爆发为更大的冰刺阵。
- **命中反馈**：真实命中时才闪白、跳伤害数字与产生冲击碎片；被减速的僵尸附带蓝色冰霜覆盖。技能伤害使用更大的数字。
- **结算时机**：近战普攻约 0.1 秒出手后结算；远程普攻在弹体抵达时结算，目标提前死亡不会重复造成伤害或奖励。基础伤害、射程和攻击间隔不变。
- **操作提示**：技能名称与效果横幅、右侧可点击 Q/E 按钮、冷却倒计时、火力全开剩余时长。保留 Q/E 键盘操作。
- **稳定性**：暂停和升级会同步冻结动作、弹体与特效；重开清理遗留攻击；特效数量有上限，低帧率时不会一次跳过整段攻击表现。

## 下载测试包

进入仓库的 `dist` 目录，点击 `Brick-Outbreak-macOS.zip`，再点击 **Download raw file / 下载原始文件**。请下载该 ZIP 文件，而不是 GitHub 的整个源码压缩包。`dist/SHA256SUMS.txt` 提供校验值，`dist/TEST-REPORT.txt` 提供验证记录。

## Mac 安装

1. 解压 `Brick-Outbreak-macOS.zip`。
2. 把 `Brick Outbreak.app` 拖进“应用程序 / Applications”。无需安装 Godot。
3. 双击打开。最低目标系统 macOS 11，通用二进制包含 Apple Silicon arm64 与 Intel x86_64。
4. 这是临时签名测试包，未使用 Apple Developer ID 签名或公证。如果系统阻止打开，先尝试启动一次，再到“系统设置 → 隐私与安全性”中找到此应用并选择“仍要打开”。系统版本不同，提示可能略有不同。
5. 如果系统提示文件“已损坏”，请先重新解压并核对 SHA256。确认是本次测试包后，可在终端仅移除此应用的下载隔离标记：

   `xattr -dr com.apple.quarantine "/Applications/Brick Outbreak.app"`

不需要关闭系统 Gatekeeper 或修改全局安全设置。当前没有 Mac 实机测试；已在 Linux 验证游戏逻辑、实际 OpenGL 画面、macOS 导出、包内游戏资源与架构。

## 操作

- 鼠标：选择英雄、升级选项、结算按钮。
- WASD / 方向键：移动。
- 自动普攻：近战英雄攻击附近敌人；远程英雄自动命中射程内最近目标。
- Q / E：两个职业技能。空格：短距离闪避，冷却 3 秒。
- Esc：暂停 / 继续。窗口关闭按钮：退出游戏。
- 每击杀一个普通敌人获得 1 经验；升级需要当前等级 × 8 经验。升级选项期间暂停战斗。
- 02:30 首领出现，04:00 前击败首领即可获胜；血量耗尽或超时则失败。

## 范围与限制

这是验证玩法的 MVP：1 张平面地图、3 名英雄、4 类普通敌人、1 个首领、3 种升级、胜负重开、区分出手与技能的合成音效。
人物已升级为带独立武器、冠甲、披风和关节动画的原创程序化积木武将，细节仍未达到参考图精细模型水平；无常驻骑乘、联机、剧情、存档、装备系统或复杂首领招式。没有实测 Mac 性能数据。

## 开发与复现

安装 Godot 4.6.3，导入 `project.godot`，按 F6/F5 运行。

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . -- --smoke-test
godot --headless --path . --export-release macOS dist/Brick-Outbreak-macOS.zip
```

macOS 导出需安装 Godot 4.6.3 的导出模板。Linux CI 可将 XDG_DATA_HOME、XDG_CONFIG_HOME、XDG_CACHE_HOME 指向可写目录。本项目不依赖 Python 教学仓库，也没有修改该仓库。

自动化验证脚本 `tests/verify.py` 会检查退出码和错误日志，共 110 项玩法与模型检查，包括三名英雄的模型接入、关节动画、实际技能效果、3D 预览和拖动旋转，五类丧尸的模型接入、步态与扑击、网格共享、嘴部发射与命中、图鉴交互，以及近战出手时机、弹体到达结算、伤害数字、命中闪白、暂停同步、重开清理和特效数量上限；传入导出的 zip 可同时核验应用结构、架构，并使用 Linux Godot 执行包内 PCK 的同一套逻辑测试。这不等于运行了 macOS 可执行文件。

```sh
python3 tests/verify.py dist/Brick-Outbreak-macOS.zip
```


完整复现导出、源码归档、校验和与包内测试：

```sh
./build.sh
```

`hero_model.gd` 独立管理三名英雄的部件、共享材质、网格缓存和动画；`main.gd` 管理战斗、攻击结算与选人界面；`combat_fx.gd` 管理有生命周期和数量上限的刀光、弹道、冲击波、碎片与伤害数字；`zombie_model.gd` 管理丧尸外形、关节动画、材质覆盖和合并网格缓存。默认下载链接保持不变，应用版本为 0.4.0。


演示录制（仅开发用途；三名英雄依次展示普攻、Q 与 E）：

```sh
godot --path . --fixed-fps 30 --write-movie /tmp/brick-combat.avi -- --combat-demo
ffmpeg -i /tmp/brick-combat.avi -c:v libx264 -crf 23 -pix_fmt yuv420p -movflags +faststart -c:a aac dist/combat-demo.mp4
```

演示中使用固定位置的重甲僵尸，并停用敌方攻击，以便观察效果；常规游戏的敌人仍正常追击和攻击。视频是在 Linux 软件渲染环境录制，不代表 Mac 实机帧率。
